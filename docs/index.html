摇卦

三枚铜钱，六次掷出。卦不可重。

摇卦是一个易经起卦应用：铜钱法六爻可变，梅花易数按时间或数起卦。卦辞爻辞据《周易》通行本，与维基文库逐条校对；白话解释为本应用原创。

全部内容随安装包下发，不连接任何服务器，离线可用。你写下的问题和摇出的卦只保存在你自己的设备上。

常见问题

换手机了，卦记怎么带走？

在「卦记 → 备份 → 导出备份文件」里导出一个 JSON 文件，存到你找得到的地方（文件、网盘、发给自己都行），在新手机上用「从备份恢复」读回来。恢复时同一条卦记以本机的为准，不会覆盖你后来新摇的卦。

卦记会不会丢？

卦记只存在设备本机，不上传服务器。卸载应用、清理存储、换设备都会让它们消失，我们这边没有副本，也无法帮你找回。请定期导出一份备份。

为什么同一个问题不能重摇？

《蒙》卦说「初筮告，再三渎，渎则不告」。摇铜钱时每掷出一爻就立刻落盘，刷新或退出都无法重来——能无限重摇的卦，结果就不值得认真对待。梅花易数讲「心动则占」，不受这条限制。

七日回访的提醒没来？

提醒是设备上的本地通知。请在系统「设置 → 通知 → 摇卦」里确认已允许通知；关闭过通知的话，之前排好的提醒不会补发。

需要注册或联网吗？

不需要注册，没有账号，也不需要网络。应用不会向任何服务器发送数据。
